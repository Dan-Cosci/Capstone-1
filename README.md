# YouTube Clone Rip-Off

This project is a simple YouTube clone created while following a tutorial by **SuperSimpleDev** on HTML and CSS. It serves as a learning project to understand the basics of web development, including layout creation, styling, and responsive design.

## Features

- **Homepage Layout**: Mimics YouTube's homepage structure with video thumbnails, titles, and descriptions.
- **Responsive Design**: Adjusts to different screen sizes for better usability.
- **Navigation Bar**: Includes placeholders for search functionality, profile icons, and menus.
- **Video Section**: Display of video cards with image thumbnails and metadata.

## Technologies Used

- **HTML**: Structure of the webpage.
- **CSS**: Styling and layout adjustments.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Dan-Cosci/Capstone-1.git
   ```

2. Open the `index.html` file in your browser to view the project.
